# STRIDEHAUS

STRIDEHAUS is a modern premium men's footwear website designed for customers who value style, quality, and confidence. The website presents a curated collection of formal shoes, sneakers, boots, casual footwear, and outdoor shoes through a bold, immersive shopping experience.

## About the Website

The website combines a luxury fashion aesthetic with a simple online-store experience. Visitors can explore featured products, browse the complete collection, filter shoes by category, sort products by price or name, view product details, select an EU shoe size, and add items to a shopping cart.

STRIDEHAUS is presented as a Cebu-based footwear brand serving customers in the Philippines. Product prices are displayed in Philippine pesos, and the website includes information about shipping, VAT, returns, store hours, and customer support.

## Main Pages

- **Home** – Brand introduction, animated hero section, featured products, customer-focused promises, and calls to action.
- **Products** – Full product catalog with category filters, sorting options, product tags, detailed product modals, and size selection.
- **Cart** – Selected products, shoe sizes, quantity controls, subtotal, shipping, VAT, and total amount.
- **About** – STRIDEHAUS history, mission, vision, values, milestones, and team members.
- **Contact** – Store address, contact details, business hours, social links, and a message form.
- **Register** – STRIDE Club registration form with customer information, delivery details, password fields, and membership benefits.
- **Thank You** – Confirmation screen shown after registration or checkout.
- **Biography** – Personal student biography and portfolio page included as part of the project.

## Website Features

- Responsive design for desktop, tablet, and mobile screens.
- Dark luxury-inspired interface with gold accent colors.
- Animated page transitions and interactive hover effects.
- Mobile navigation menu.
- Featured product cards and product badges.
- Product category filtering and sorting.
- Product detail modal with EU sizes 39–45.
- In-memory shopping cart with quantity management.
- Free shipping for orders of at least **₱3,000**.
- 12% VAT calculation in the cart summary.
- Image fallback handling when external product images fail to load.
- Animated checkout confirmation with order status steps and confetti.

## Design and Brand Identity

The STRIDEHAUS design uses a premium black-and-gold color palette to communicate confidence, exclusivity, and craftsmanship. Large condensed headings use **Bebas Neue**, while interface text uses **Inter** for readability. Product photography, subtle grid patterns, gold highlights, smooth transitions, and motion effects create an editorial fashion-store atmosphere.

## Running the Project

Install the dependencies:

```bash
pnpm install
```

Start the development server:

```bash
pnpm dev
```

Create a production build:

```bash
pnpm build
```

Preview the production build:

```bash
pnpm preview
```

## Current Project Scope

This project is currently a front-end website demonstration. The cart is stored only in application memory, so it resets when the page is refreshed. Registration, contact submission, promo codes, payment processing, customer accounts, and order storage are visual demonstrations and are not connected to a backend service.

Product images are loaded from external Unsplash URLs, and some social media links are placeholders. A production version could connect the website to a product database, authentication system, payment provider, order management system, and customer support service.
